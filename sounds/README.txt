# Air Spell Arena – 오디오 파일 폴더

이 폴더에 오디오 파일을 넣으면 게임 설정 화면에서 자동으로 인식됩니다.

## 지원 형식
- BGM (배경음악) 슬롯: .wav / .ogg / .mp3
- SFX (마법 효과음) 슬롯: .wav / .ogg 권장 (.mp3는 환경에 따라 지원 안 될 수 있음)

## 사용 방법
1. 원하는 오디오 파일을 이 폴더(sounds/)에 복사합니다.
2. 게임 메뉴에서 [SETTINGS] 버튼을 클릭합니다.
3. BGM 슬롯과 SFX 슬롯에 각각 원하는 파일을 선택합니다.
4. [▶ 듣기] 버튼으로 미리 들어볼 수 있습니다.
5. [저장] 버튼을 누르면 audio_config.json에 설정이 저장됩니다.
