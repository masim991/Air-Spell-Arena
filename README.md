# Air Spell Arena

웹캠 모션 캡처로 마법을 시전해 보스와 싸우는 파이썬 게임.
MediaPipe(손/얼굴 추적) + OpenCV(카메라) + Pygame(게임 렌더)로 동작합니다.

## 설치

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

- **Python 3.12 필요** (MediaPipe 0.10.x 는 3.9~3.12 지원, 3.13 미지원).
- GPU 불필요. CPU 추론으로 동작합니다.

## 실행

```bash
python main.py
```

- Pygame 창(게임)과 OpenCV `Tracking` 창(웹캠 미러)이 함께 뜹니다.
- 종료: 게임 창에서 `ESC`, 또는 `Tracking` 창에서 `q`.
- `main.py` 상단 옵션:
  - `SHOW_DEBUG_WINDOWS` — 웹캠 디버그 창 표시 여부.
  - `CAMERA_INDEX` — 웹캠이 여러 대일 때 조정.
  - `USE_HAND_TRACKING` — `True`: MediaPipe 손가락 추적, `False`: HSV 색상 마커 추적(`air_canvas.py`).

## 조작

### 1. 포즈 주문 (한 손 — 손 모양을 약 5프레임 유지)
| 포즈 | 주문 |
|------|------|
| 손바닥 펼치기(다섯 손가락) | FIRE |
| 주먹 | WATER |
| 엄지만 세우기 | EARTH |
| 검지만 펴기 | WIND |

### 2. 궤적 주문 (검지 끝으로 허공에 그리기)
| 궤적 | 주문 |
|------|------|
| 왼쪽으로 수평 이동 | LIGHT (실드) |
| 오른쪽으로 수평 이동 | DARK |
| 원 | CIRCLE → 실드 |
| 지그재그 | ZIGZAG → 라이트닝 (쿨다운 4초) |

두 개의 기본 주문을 1.2초 안에 연속 시전하면 콤보로 합쳐집니다
(`spell_combo.py`: FIRE+WATER→STEAM 등).

### 2.5. 듀얼 캐스팅 (양손)
양손이 동시에 잡히면 규칙은 한 줄입니다 — **같은 손모양은 증폭, 다른 손모양은 융합.**

| 양손 | 결과 |
|------|------|
| 같은 손모양 두 개 | **AMPLIFY** — 그 주문의 위력 2배 (마나는 1.6배) |
| 다른 손모양 두 개 | **FUSION** — 두 원소의 상위 주문이 즉시 발동 |

융합표(좌우 구분 없음): 불+물→STEAM · 불+바람→TORNADO · 흙+불→STONE_BULLET ·
물+바람→ICE_SHARD · 흙+물→MUD · 흙+바람→BLINDNESS(모래폭풍).

시간축 콤보(1.2초 안에 두 번 시전)와 달리 **동시에 만들면 되므로 타이밍 곡예가 없습니다.**

### 2.7. 마나
모든 주문은 마나를 소모하고(기본 11~20, 콤보 24~38), 초당 18씩 자동 회복됩니다.
완전히 고갈되면 0.7초간 회복이 멈추므로 바닥까지 긁어 쓰지 않는 편이 좋습니다.
**회복을 기다리는 동안 손을 내려도 되기 때문에, 팔을 계속 들고 있을 이유가 없습니다.**

### 3. 머리로 회피
얼굴을 **왼쪽/오른쪽으로 살짝만 돌리면** 플레이어가 그 방향으로 이동해 보스 투사체를 피합니다.
(코끝이 얼굴 안에서 어느 쪽에 있는지로 판정하므로 과한 움직임이 필요 없고,
카메라 위치·거리와 무관합니다.) 정면을 보면 서서히 중앙으로 복귀합니다.
`Tracking` 창에서 **`c` 키**를 누르면 현재 자세를 정면으로 재보정합니다.

### 4. 키보드 폴백 (데모·테스트·접근성)
타이틀 화면에서 **PLAY WITHOUT CAMERA** 버튼을 누르면 카메라/모션 인식 없이 바로 시작합니다
(웹캠이 없거나 초기화에 실패해도 게임은 계속 뜨고, 자동으로 이 모드로 대체됩니다).
게임 진행(playing) 중:
| 키 | 동작 |
|----|------|
| `1`~`7` | FIRE / WATER / WIND / EARTH / DARK / LIGHT / LIGHTNING |
| `←` `→` | 좌/우 회피 (누르는 동안 이동, 카메라보다 우선) |
| `C` | **카메라 켜기/끄기 (실시간 전환, 재시작 불필요)** |
| `V` | 점술 수정구(웹캠 화면) 켜기/끄기 |
| `R` | 하이라이트 녹화 켜기/끄기 |
| `ESC` | 일시정지 |

메뉴 화면 단축키: `D` 오늘의 챌린지 · `K` 포즈 재확인 · `S` 앉은 자세 모드 · `F` 저장물에 얼굴 포함 ·
`C` 카메라 토글 · `N` 카메라 번호 변경 · `G` 주문 가이드 · `1`~`4` 난이도.

키보드 폴백은 데모·접근성용 보조 입력이며 카메라 모드와 **동등하지 않습니다**:
양손 융합/증폭(듀얼 캐스팅)과 머리 방향 회피, 궤적 주문은 사용할 수 없고
주문 7종을 키로 직접 고르는 방식입니다. 마나와 룬은 동일하게 적용됩니다.

### 5. 성장 룬 (로그라이크)
스테이지를 클리어할 때마다 **3장 중 1장**을 고릅니다(`1`/`2`/`3` 키 또는 클릭).
마나 회복, 주문 피해, 받는 피해 감소, 적중 시 흡혈/마나 회복, 듀얼 증폭 강화 등
12종이 있으며 일부는 중첩됩니다. 룬은 **한 체인(런) 동안만** 유지되고,
새 런을 시작하면 초기화됩니다 — 같은 사다리를 올라가도 매번 다른 빌드가 됩니다.

### 5.5. 오늘의 챌린지 (일일 시드)
메뉴의 **DAILY CHALLENGE** 버튼(또는 `D` 키)으로 시작합니다.
날짜 하나로 **보스 순서 · 난이도 · 룬 후보 · 변형 규칙**이 전부 고정되므로,
같은 날 플레이한 사람은 모두 **같은 판**을 받습니다. 서버도 계정도 필요 없습니다.

변형 규칙 6종이 매일 바뀝니다 — GLASS CANNON(주고받는 피해 1.5배),
MANA DROUGHT(회복 30%↓), SWIFT DOOM(보스 공격 주기 25%↓),
ARCANE ECONOMY(소모 30%↓·피해 20%↓), TWINBOUND(듀얼 증폭 +1.0배·한 손 25%↓), PURE(변형 없음).

날짜별 최고 점수와 **연속 플레이 일수(스트릭)** 가 로컬에 기록되고,
결과 카드에는 시드(예: `#E7F749`)가 찍혀 같은 판인지 대조할 수 있습니다.

### 6. 점술 수정구 (인게임 웹캠) · 공유 카드 · 하이라이트 클립
웹캠 영상이 게임 화면 우하단의 원형 "수정구"로 실시간 표시됩니다.
시전할 때마다 주문 색으로 빛납니다. 인게임 `V` 키로 켜고 끌 수 있습니다(설정은 저장됩니다).

> **개인정보 안내 — 저장되는 것들**
> - 런이 끝나면 결과 카드(1200×630 PNG)가, 승리하면 하이라이트 클립(MP4)이 **자동 저장**됩니다
>   (저장 위치는 아래 "저장 위치" 표의 `clips/`).
> - **기본값은 얼굴을 가린 채 저장**합니다: 카드에는 웹캠 사진 대신 마법진만, 클립에서는
>   수정구 영역을 덮어서 녹화합니다. 가려진 영상은 메모리의 15초 버퍼에도 들어가지 않습니다.
> - 얼굴을 담고 싶다면 **메뉴에서 `F` 키**를 눌러 켜세요(메뉴에 현재 상태가 항상 표시됩니다).
>   켜면 수정구에 보이는 실제 웹캠 영상이 PNG/MP4에 그대로 저장되고 공유 시 노출됩니다.
> - 저장 자체는 인게임 `R`(클립) 키로 끌 수 있고, 카드는 `save_data.json`의 `save_cards: false` 로 끕니다.
> - 최초 실행 시 게임 안에서도 이 사실을 한 번 고지합니다. 카메라 영상은 외부로 전송되지 않으며
>   로컬 `clips/` 에만 남습니다. 공유 전에 직접 확인하세요.

런이 끝나면 결과 카드가 `clips/` 에 자동 저장됩니다 —
점수·통계·획득 룬이 들어간 공유용 이미지입니다(얼굴 포함은 위 설정에 따름).

**승리하면 직전 15초가 영상(mp4)으로도 저장됩니다.** 게임이 항상 최근 15초를
링버퍼로 들고 있다가 보스를 쓰러뜨리는 순간 굽습니다 — 녹화 프로그램을 따로
켤 필요가 없습니다. 인코딩은 워커 스레드가 처리해 게임 프레임을 끊지 않습니다
(640×360 / 20fps, 인게임 `R` 키로 끄기 가능). 저장 경로는 엔딩 화면에 표시됩니다.
수정구를 `V` 로 끄거나 얼굴 포함이 꺼져 있으면 클립에 얼굴이 담기지 않습니다.

## 보스

보스는 HP에 따라 3페이즈로 강화되며(원소 FIRE→WATER→DARK, 공격 가속),
시전 0.5초 전 붉은 경고 링이 표시됩니다. 주문 상성이 맞으면 1.5×, 불리하면 0.6× 피해.

### 7. 캘리브레이션 · 앉은 자세 모드
최초 실행 시 **포즈 확인 온보딩**이 먼저 뜹니다. 네 가지 손 모양과 양손 인식이
*실제 내 카메라에서* 잡히는지 하나씩 확인시켜 주며, 지금 무엇으로 인식되는지를
실시간으로 보여줍니다. 메뉴의 `K` 키로 언제든 다시 열 수 있고, `ESC`로 건너뛸 수 있습니다.

메뉴에서 `S` 키를 누르면 **앉은 자세 모드**가 켜집니다. 팔꿈치를 책상에 둔 채
플레이할 수 있도록 손 모양 판정 여유를 키우고(기울어진 손도 인정), 유지 프레임을
줄이며, 고개 회전 감도를 약 1.45배로 올립니다. 팔을 앞으로 뻗어 유지할 때 생기는
어깨 피로(고릴라 암)를 줄이기 위한 접근성 옵션입니다.

## 카메라 요구사항
- 720p 웹캠 권장, 30 FPS 이상.
- 상반신과 한쪽 손이 프레임에 들어오는 거리(약 0.6~1.2 m).
- 균일한 조명(역광 피하기). 손과 배경 대비가 낮으면 인식률이 떨어집니다.

### 저장 위치 (실행 폴더와 무관)

| 실행 방식 | 읽기 전용 에셋(`sounds/`) | 쓰기 데이터(`save_data.json`, `audio_config.json`, `clips/`, `sounds/custom/`) |
|-----------|--------------------------|------------------------------------------------------------------------------|
| 소스 체크아웃 | 저장소 폴더 | 저장소 폴더 |
| PyInstaller 빌드 | 번들(임시 해제 폴더) | `%APPDATA%\AirSpellArena` (macOS/Linux는 각 사용자 데이터 폴더) |

환경변수 `AIR_SPELL_ARENA_HOME` 으로 쓰기 데이터 위치를 직접 지정할 수 있습니다.
`pip install .` 로 설치한 경우 `sounds/` 는 휠에 포함되지 않으므로 소리 없이 실행됩니다(게임 진행에는 영향 없음).

## 오디오 권리 (배포 전 필독)

- 이 저장소의 **모든 오디오 파일(`sounds/*.mp3`, `sounds/custom/*.mp3`)은 출처·이용 허락이
  문서로 확인되지 않았습니다.** 파일 메타데이터에도 저작권/라이선스 정보가 없습니다.
- 특히 `sounds/custom/` 은 제3자 음원일 가능성이 있어 **PyInstaller 빌드에 포함하지 않습니다**
  (`airspellarena.spec` 에서 제외). 사용자가 자기 데이터 폴더의 `sounds/custom/` 에 직접 넣어 쓰는 용도입니다.
- 최상위 `sounds/` 파일도 권리 확인 전에는 **공개 배포·업로드를 하지 마세요.** 빌드 스펙은
  기본적으로 `sounds/` 를 번들하지 않으며(무음 빌드), 권리 확인을 끝낸 뒤에만
  `AIRSPELL_AUDIO_CLEARED=1` 로 포함합니다. **이 확인은 공개 릴리스의 게이트입니다.**
  배포하려면 직접 제작했거나 상업/재배포가 허용된 음원으로 교체하고 출처를 이 문서에 기록해야 합니다.
- 저장소에는 `sounds/custom/` 파일이 아직 추적되고 있습니다. 공개 저장소로 올리기 전에 제거를 검토하세요.

## Blender 아트

Blender 5.2.3으로 제작한 편집 원본은 `art/blender/air_spell_arena_art.blend`입니다.
`art/blender/build_assets.py`를 Blender 백그라운드 모드에서 실행하면 `assets/`의 PNG 6장을 다시 렌더합니다.

```powershell
blender -b --factory-startup --python-exit-code 1 -P art/blender/build_assets.py
```

게임은 석조 경기장 배경, 1인칭 플레이어 지팡이, ARCANE/FROST/VOID 보스 이미지를 사용합니다.
플레이어 전신 모델은 Blender 원본과 `assets/player_mage.png`에 들어 있으며 현재 전투 화면에서는 지팡이만 보입니다.
아트 파일이 없으면 기존 Pygame 도형 렌더링으로 전환합니다. PyInstaller 빌드에는 `assets/`가 포함됩니다.
현재 모델은 렌더용 로우폴리이며 리깅·캐릭터 애니메이션은 포함하지 않습니다.
