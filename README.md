# Air Spell Arena

웹캠 앞에서 손 모양과 손끝 궤적으로 마법을 시전하고, 고개를 좌우로 움직여 회피하는 1인칭 마법 대전 게임입니다.

## 실행

```bash
pip install -r requirements.txt
python main.py
```

- 웹캠이 필요합니다. (MediaPipe Hands + Face Mesh 사용)
- `ESC` 일시정지 / 메뉴, 마우스로 난이도·사운드 설정 변경.

## 조작

| 입력 | 주문 |
| --- | --- |
| 손바닥 펴기 | FIRE |
| 주먹 | WATER |
| 엄지 척 | EARTH |
| 검지만 펴기 | WIND |
| 손끝을 왼쪽으로 긋기 | LIGHT |
| 손끝을 오른쪽으로 긋기 | DARK |
| 손끝으로 원 그리기 | SHIELD (2.5초 피해 50% 감소) |
| 손끝으로 지그재그 | LIGHTNING (쿨다운 4초) |
| 고개 좌/우 | 플레이어 좌우 이동(회피) |

## 콤보

기본 주문을 **1.2초 안에 연속으로 두 번** 입력하면 상위 주문이 발동합니다.
입력 대기 중에는 화면 하단에 대기 주문과 남은 시간 게이지가 표시됩니다.

| 콤보 | 결과 | 효과 |
| --- | --- | --- |
| FIRE → WATER | STEAM | 피해 + 지속 피해(화상) |
| WATER → FIRE | MUD | 보스 회피 봉쇄 |
| FIRE → FIRE | FLAME_BALL | 고위력 단발 |
| WATER → WATER | ICE_SHARD | 보스 회피율 둔화 |
| WIND ↔ FIRE | TORNADO | 4단 히트 |
| EARTH ↔ FIRE | STONE_BULLET | 회피 무시(관통) |
| LIGHT → DARK | BLINDNESS | 보스 명중률 감소 |
| DARK → LIGHT | CURSE_SHOCK | 피해 + 플레이어 HP 흡수 |

## 원소 상성

보스는 항상 하나의 **약점 원소**를 가지며 15초마다, 그리고 페이즈가 바뀔 때마다 변경됩니다(화면 상단 표시).

- 약점 원소로 명중: 피해 **2배** + 보스 경직(0.7초)
- 약점의 상극 원소(FIRE↔WATER, EARTH↔WIND)로 명중: 피해 **0.5배**

## 보스 페이즈

보스는 공격 전에 항상 **예고(수축하는 링)** 를 표시합니다. 예고 종류에 따라 대응이 다릅니다.

| 페이즈 | HP | 패턴 |
| --- | --- | --- |
| 1 | 100~70% | 단발 조준 |
| 2 | 70~30% | 3연사 / 좌우 스윕 / 단발 |
| 3 | 30% 이하 | 광역기 / 3연사 / 좌우 스윕 |

- 단발·연사·스윕: 고개를 움직여 회피
- 광역기(화면이 붉게 물듦): 회피 불가 — **SHIELD 필수**

## 테스트

```bash
pip install -r requirements-dev.txt
pytest -q
```

테스트는 웹캠 없이 실행되며, 헤드리스 환경에서는 SDL 더미 드라이버를 사용합니다.
